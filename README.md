# 订单视觉定位（Order Visual Locator）

手机端单页 Web 应用：**拍单据照片 → OCR 识别批号/委托单位/件数 → 选择区域 → 一键归档**，并支持记录检索、搜索、导出。

界面沿用源文档 `DOCTYPE html.html` 的设计语言（薄荷绿主色、圆角卡片、三列区域宫格、记录列表），本次重点重做了**视觉识别链路**。

## 为什么之前识别不出东西

排查后有两个硬性原因，都已修复：

1. **CDN 不可达**：原页面从 `cdn.jsdelivr.net` 加载 Tesseract.js，并且引擎的 `workerPath`、`corePath` 默认也走 jsdelivr。该域名在当前网络不可用，所以脚本根本加载不出来，识别自然毫无反应。
   现在改为**多线路自动切换**（unpkg → npmmirror → jsdelivr），并显式指定 worker / 核心 / 语言包地址；实测 unpkg 与 npmmirror 可访问。
2. **`file://` 限制**：双击打开时浏览器会禁止页面创建 OCR 工作线程（`blob:null`），识别会直接失败。
   现在页面对此有检测与提示，并附带 `启动服务.bat` / `serve.js`，用 `http://localhost` 打开即可。

## 识别功能做了哪些增强

| 能力 | 说明 |
| --- | --- |
| **固定识别区域** | 同一版式单据只需框选一次（如左上角批号行），之后每张新照片自动只识别该区域；按比例保存、随图片缩放，带 0.6% 余量容错，可随时暂停 |
| **国检单预设** | 内置「国检单 · 批号行」坐标预设（针对 688×457 的国检中心委托检验合同），一键套用，可再手动微调 |
| 区域可视化 | 固定区域以虚线框标在原图上，旁边显示裁剪缩略图，随时确认框得准不准 |
| 多线路引擎 | 依次尝试 unpkg → npmmirror → npmmirror 中文包，任一可用即锁定；初始化有 75s / 45s 空闲超时保护 |
| 明确资源路径 | 不再依赖默认 CDN：`workerPath` / `corePath` / `langPath` 全部显式配置 |
| 双通道识别 | 先在目标区域识别；关键字段少于 2 个时，自动做灰度 + 对比度拉伸 + 放大后再识别一次，取更优结果 |
| 框选识别 | 临时框选某块（放大最多 6 倍、单块版面 PSM 6）识别，不改变固定区域 |
| 字段解析 | 批号/单号、委托单位、总件数、克重四类；标签允许「批 号」断字；同一单出现多个批号时按「含字母、长度、非日期」打分择优，避免误取检测编号或日期串 |
| 候选点选 | 识别出的所有编码/数字以标签列出（单号/克重/件数），点一下直接填入对应字段 |
| 原图标注 | 单号绿框、克重蓝框、件数橙框，框选/固定区域识别时按裁剪与放大倍率换算坐标 |
| 自检 | 「测试识别」用 Canvas 现场生成一张订单样张跑完整流程，能验证引擎是否正常 |
| 诊断面板 | 右上角脉冲图标：访问方式、引擎脚本来源、识别线路、上次耗时/置信度、事件日志，可一键复制 |

## 固定识别区域（针对批号行）

整页识别会把二维码、检测编号、电话、表格里的数字都读进来，噪声大。现在可以锁定一个固定区域：

1. 先拍一张单据（或选中图片），点工具栏的 **「固定区域」**。
2. 选 **「在图上框选固定区域」**，在图上拖出只包含「批 号：PX…  委托单位：…」这一行的矩形；
   或者直接点 **「套用国检单批号行」** 使用内置预设。
3. 保存后，该区域按**比例**记在浏览器里，之后每次拍照都会自动只识别这块，不再读整张表。
4. 预览图上的虚线框就是当前范围，右侧缩略图可核对；「自动：开/关」可随时暂停。

字段映射：**批号 → 单号 / 批号**，**委托单位 → 委托单位 / 客户**，**总计/数量 → 件数**，带 g/克的数字 → 克重。

预设坐标是针对 688×457 的国检单版式标定的；如果你的扫描件留白比例不同，框选一次即可覆盖。

## 打开方式（推荐）

双击 **`启动服务.bat`** 即可，**不需要安装 Python 或 Node.js**。

启动器会调用 Windows 自带的 PowerShell 运行 `serve.ps1`（一个极简本地静态服务器），自动选 8080–8089 中空闲的端口，并打开浏览器：

```
http://localhost:8080/index.html
```

- 关闭那个黑色命令行窗口即停止服务。
- 如果你的机器上已有 Python/Node（且 PowerShell 被安全策略禁用），启动器会自动退回 `py` / `python` / `node` 方式。
- 手动方式：`powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1`，或 `python -m http.server 8080`、`node serve.js 8080`。

> 直接双击 `index.html` 也能打开，但 Chrome 会禁止 OCR 线程，识别会提示失败并自动弹出诊断；记录、区域、手动录入仍可用。

首次识别需要联网下载中文语言包（约 15–20MB，之后走浏览器缓存）。没有网络时可用「手动录入」，其余功能不受影响。

## 验证识别是否正常

1. 用 `启动服务.bat` 打开页面，右上角状态显示「OCR 就绪 · unpkg」或「npmmirror」。
2. 点 **「测试识别」**（主界面或诊断面板里都有）：它会现场生成一张订单样张跑完整识别，成功会提示「自检通过，已填入示例字段」。
3. 自检通过说明引擎与网络没问题；真实单据建议先套用「国检单批号行」固定区域，再拍。

## 使用流程

1. 第一次使用：点「固定区域」→「套用国检单批号行」（或用「在图上框选固定区域」自己框），之后无需重复设置。
2. 点「拍照识别」拍摄单据；桌面端可拖拽图片或 `Ctrl+V` 粘贴截图。
3. 识别只跑固定区域，自动填入批号与委托单位；需要时点「全图识别」读整张，或点「框选识别」临时选一块。
4. 点选存放区域，点「保存定位」；保存后可点 Toast 的「撤销」。
5. 在「记录」页搜索、按区域筛选、导出 CSV。

## 定制

- **区域名称**：右上角「区域管理」增删改，或改 `index.html` 中的 `DEFAULT_AREAS`。
- **主题色**：改 `:root` 的 `--mint / --mint-dark / --mint-soft`。
- **字段规则**：`RX` 对象集中定义四类正则；`collectCandidates` 控制候选生成。
- **纯内网部署**：把 `tesseract.min.js`、`worker.min.js`、`tesseract.js-core@5.1.1` 的 `tesseract-core-simd-lstm.wasm.js`（及 `.wasm`）和 `chi_sim.traineddata.gz`、`eng.traineddata.gz` 下载到本地，改 `OCR_SOURCES` 为相对路径即可完全离线。

## 说明

源文档 `DOCTYPE html.html` 只包含 120 行（`<head>` 与部分 CSS，止于 `@keyframes recIn{fr`），没有 `<body>` 和脚本，是未下载完整的缓存文件。本应用据此重建：保留其配色、字号、圆角、阴影、宫格与列表样式，并按「订单视觉定位」主题补全识别、归位与记录管理。若你有完整原文件（含业务规则），发来可再做 1:1 对齐。

## 数据与备份

- 记录存在当前浏览器 `localStorage`，**换设备/清缓存会丢失**，重要数据请定期「导出 CSV」。
- 单设备最多 500 条；缩略图只保留最近 120 张以控制存储。
