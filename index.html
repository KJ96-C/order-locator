云同步 · GitHub Issues

    
  

  
把每条记录存成 GitHub 仓库的一个 Issue，实现多设备同步。配置一次，之后点「立即同步」即可。


  

    

    

    

    

  


  

    
    
  

  

  


  

    第一次怎么配置（约 3 分钟）
    
    
      
  1. 在 GitHub 新建（或选用）一个仓库，记下“用户名”和“仓库名”。
    2. 
      
  2. 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，勾选 repo 权限，复制生成的 token。
    3. 
      
  3. 把三项填到上面 → 点「保存配置」→ 点「立即同步」。
    4. 
      
  4. 其他设备同样填这三项后点「立即同步」，即可互相看到记录。
    5.
